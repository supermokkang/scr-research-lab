# SCR Research Lab v1.1 — 신호 타이밍 정밀 검증

기존 Streamlit 앱에 `app.py`와 `engine.py`를 **둘 다** 덮어쓴 후 자동 배포합니다. 동일한 저장소 최상위 위치에 있어야 합니다.

## 변경
- 원문 HTS 차트의 검은 **Stochastic Fast %K(5)**를 과매수/과매도 및 순차 회복의 판정 본선으로 사용합니다. 파란 **%D(3)**는 보조선입니다. (이전 코드는 평활된 %D를 판정 기준으로 사용해 시점을 늦출 가능성이 있었습니다.)
- CCI(20)·RSI(14)는 동일한 순차 탈출 규칙 유지, 임의 시간 제한 없음.
- 매수/매도 신호가 확정된 봉 날짜와 S/C/R 각각의 탈출 날짜, **마지막 탈출 지표**를 표·CSV로 출력합니다.
- 기존 매수 빨간선/매도 파란선, 일·주·월 보조 차트, 채색, 거래별 수익률 유지.
- **봉 마감 신호일과 다음 봉 시가 체결일은 구분**합니다. 수익률 계산의 체결일을 과거로 옮기는 변경은 하지 않았습니다.

## 중요한 한계
- 사진을 통한 추론이므로 해당 HTS의 Stochastic, CCI, RSI 계산 세부 사항과 수정주가/차트 설정을 정확히 검증한 것은 아닙니다.
- 원문은 과매도 기준선과 지표별 순차 탈출을 보여주지만 과매도 진입 이력 초기화는 정확한 공식이 공개되지 않았습니다. 현재는 긴 기간 보유할 수도 있습니다.
- Yahoo 조정 시세와 HTS 데이터 공급자 및 배당/분할 반영 방식이 다르면 신호 시점이 달라질 수 있습니다.
- 과거 주봉에 표시되는 빨간 세로선은 **해당 주 마지막 거래일 종가**에서 확정되고, 백테스트 실제 매수는 다음 거래 주 시작 시가입니다.
- 실제 2025년 VOO 원문 매수 주차와 직접 대조한 실측 데이터 테스트는 수행하지 않았습니다.
