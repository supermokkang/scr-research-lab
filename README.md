# SCR Research Lab v0.9 — 순차 탈출 완료

## 변경 사항
- 기본 매수: S·C·R 각각 과매도 기준 이하를 경험하고, 이후 순서에 관계없이 각 기준을 상향 탈출. 마지막 지표가 완료한 봉에 매수 신호.
- 기본 매도: S·C·R 각각 과매수 기준 이상을 경험하고 순차 하향 탈출. 마지막 탈출 봉에 매도 신호.
- 기존 엄격/순차/Signal선 가설은 비교용으로 유지.
- 기간 제한은 원문 미확정이므로 사용자가 설정(기본 26봉).
- 세 타임프레임 표시·채색·수익률 보고 기존 기능 유지.

## 업로드
GitHub 루트의 `app.py` 및 `engine.py`를 새 파일로 교체, Commit changes.
`requirements.txt`는 그대로 사용 가능합니다.

## 중요
원문 차트와 2023·2025 실제 신호 날짜 대조는 미완료입니다. 미국/한국/일본 시세 실접속 검증은 배포 후 필요합니다.
