# SCR Research Lab v1.2

기존 v1.1 위에 적용하는 화면 개선/진단 패치입니다.

## 변경
- 가격 캔들 양봉 빨간색, 음봉 파란색 (상세·월/주/일 통합 차트)
- '신호 전후 4주 · CCI 기준선 교차 확인' 표: 매수 신호 4봉 전부터 2봉 후까지, CCI/전주 CCI, 기준선 교차 여부, S/R 확인
- 기존 SCR 순차 탈출 판정 및 거래 체결 방식 변경 없음. 매수 날짜를 인위적으로 앞당기지 않음.

## 업로드
GitHub 저장소 최상단의 `app.py`만 교체하면 됩니다. `engine.py`도 패키지에 동봉하지만 v1.1과 동일합니다.

## 해석
2025-05-02 CCI 값이 -43.20, 직전 값이 -112.23이라면 -100 상향 교차가 5/2에 기록된 것이 현 계산상 맞습니다. 원문 HTS와의 차이를 확인하려면 HTS 종가/수정주가, 원문 CCI 수식, 주봉 시작/끝 기준을 대조해야 합니다.

검사: Python 컴파일 및 저장소에 포함된 2개 자동 테스트 통과. Streamlit 온라인 배포 및 실제 VOO 데이터 검증은 수행하지 못했습니다.
